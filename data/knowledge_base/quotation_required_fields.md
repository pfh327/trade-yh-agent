# Quotation Required Fields

For most B2B trade inquiries, the customer should provide:

- Product name
- Product photo, drawing, sample, or URL
- Expected quantity
- Option, size, material, color, or specification
- Desired delivery date
- Destination
- Packaging, label, logo, and origin-marking requirement
- Inspection requirement
- Target price or budget if available

If the inquiry is incomplete, the agent should ask for the smallest number of high-impact missing fields first.
